# Code of conduct

We welcome contributors with different backgrounds and levels of experience.
Treat people respectfully, give constructive feedback, and focus disagreement
on ideas and code. Respect privacy and credit others' work.

Harassment, discriminatory language, threats, personal attacks, sexualized
content, and sharing private information without consent are not acceptable.
These expectations apply to this repository's issues, pull requests and other
project spaces.

Report concerns privately to [ajay.kumar@nonstopio.com](mailto:ajay.kumar@nonstopio.com),
the maintainer contact listed in the repository metadata. Include links and
context where possible. Maintainers will review reports, protect reporter
privacy as far as possible, and may remove content, limit participation, or
exclude contributors according to the circumstances. Maintainers are expected
to apply these standards fairly.
